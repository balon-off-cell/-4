# Генератор коммерческих предложений (КП) и конъюнктурного анализа

Веб-приложение + CLI для автоматического формирования:

1. **Конъюнктурного анализа (КА.xlsx)** — по 3 коммерческих предложения на каждую позицию сметы
2. **Коммерческих предложений (КП.pdf)** — в стиле эталонных бланков

## Возможности

- Загрузка сметы / спецификации (Excel) — поддерживается ЛСР Гранд-Смета и простые таблицы
- Автоматическое создание **3 предложений** на позицию (ЛУИС+, ЭТМ, Машпромлизинг)
- Выбор самого дешёвого предложения («+»)
- Расчёт цены без НДС (= цена с НДС / 1.2)
- Формирование кода ресурса по Методике
- Скачивание готового КА.xlsx и КП.pdf прямо из браузера

## Быстрый старт (локально)

### 1. Установка

```bash
git clone https://github.com/ВАШ_ЛОГИН/kp-generator.git
cd kp-generator
pip install -r requirements.txt
```

Нужен также **poppler** (только если используете извлечение логотипов из PDF-бланков):

- Ubuntu/Debian: `sudo apt install poppler-utils`
- Windows: [poppler for Windows](https://github.com/oschwartz10612/poppler-windows/releases)
- macOS: `brew install poppler`

### 2. Запуск веб-версии

```bash
streamlit run app.py
```

Откроется браузер по адресу `http://localhost:8501`.

### 3. CLI (старый способ)

```bash
python main.py --estimate смета.xlsx --blank бланк.pdf --output КП.pdf --markup 1.3
```

---

## Как пользоваться веб-версией

1. Откройте приложение в браузере
2. Загрузите Excel-смету / спецификацию
3. При необходимости укажите название объекта, ФИО согласующих
4. Нажмите **«Сформировать конъюнктурный анализ»**
5. Скачайте `КА.xlsx`
6. (Опционально) Сформируйте 3 КП или 1 КП только по выбранным позициям

## Развёртывание в интернет (бесплатно)

### Вариант А — Streamlit Community Cloud (рекомендуется)

1. Залейте код на GitHub (см. инструкцию ниже)
2. Зайдите на [share.streamlit.io](https://share.streamlit.io)
3. Подключите GitHub-аккаунт
4. New app → выберите репозиторий → Main file path: `app.py`
5. Deploy

Через 1–2 минуты получите публичную ссылку вида `https://ваш-логин-kp-generator.streamlit.app`

### Вариант Б — Hugging Face Spaces

1. Создайте Space типа Streamlit
2. Загрузите файлы проекта
3. В `requirements.txt` всё уже есть
